# 扫码答题程序

**一个二维码，所有人微信扫同一个码** → 随机抽 50 题 → 交卷看总分 → 题号总览 + 逐题解析 / 全体详解。

零依赖部署：双击 `start.bat` 即可用。

---

## 一、唯一入口：二维码

程序只有**一个**入口，就是投放大屏上的那张二维码。所有人扫同一个码，各自在自己手机上独立答题、各自算分，互不影响。

### 启动

```
双击 d:\quiz\start.bat
```

浏览器会自动打开 **自检页** `http://localhost:8080/selfcheck.html`，上面会显示：

| 检查项 | 含义 |
|---|---|
| 题库加载 | 题库是否读到、多少道题 |
| 题量是否够抽 | 单选 20 / 多选 20 / 判断 10 是否充足 |
| 答案是否越界 | 答案字母是否都在选项范围内 |
| 局域网地址 | 自动识别到的可访问地址 |
| 二维码地址 | 最终写入二维码的 URL |

下方直接有一张二维码，**用手机微信扫它**即可验证链路是否打通。

### 投放到大屏

打开 `http://localhost:8080/cast.html`（可全屏 / 投影），页面中央是那张二维码。
按 `Ctrl+P` 可直接打印成桌牌。

## 二、二维码里写什么地址？

这是**唯一需要你决策**的一点。程序会自动挑一个，但你可以强制指定。

### 情况 A：现场活动，手机和电脑连同一个 WiFi（最常用）

二维码内容是 `http://192.168.x.x:8080/`。

程序会**自动排除**不可用的网卡：
- VMware / VirtualBox / WSL / Hyper-V 等虚拟网卡
- Clash / v2ray / TUN 等代理隧道网卡
- 没有默认网关的独立网段网卡

只挑「有默认网关的真实局域网网卡」，优先级：无线 > 以太网，`192.168.x.x` > `10.x.x.x`。

> ⚠️ **前提：电脑必须连上 WiFi 或网线**。
> 你当前这台电脑 WLAN 是断开的，只有 Clash 虚拟网卡和 VMware 网卡，**这三个地址手机都访问不到**。
> 连上 WiFi 后重跑 `start.bat` 即可。

### 情况 B：有公网地址 / 域名（异地也能扫）

用 `set-quiz-url.bat`，交互式输入地址：

```
set-quiz-url.bat
→ 请输入要写入二维码的完整地址：https://myquiz.pages.dev/
```

二维码里就固定写死这个地址，不随网卡变化。详见 `deploy.md`。

### 情况 C：需要 https（微信体验最佳）

GitHub Pages / Vercel 托管天然带 https，见 `deploy.md`。

## 三、微信扫码的可行性

| 项目 | 结论 |
|---|---|
| 微信扫一扫能否打开 `http://192.168.x.x:8080/` | ✅ 可以。首次可能提示「非微信官方网页」，点「继续访问」即可 |
| 局域网地址是否安全 | ⚠️ 是 http，个别浏览器提示「不安全」，不影响答题功能 |
| 同一 WiFi 下手机能否访问电脑 | ✅ 可以，这是标准局域网通信 |
| 人多时是否有限制 | ✅ 无限制，每个手机各自请求静态文件，互不影响 |
| 断网能否用 | ✅ 可以，局域网方案不依赖互联网 |

### 已做的微信内置浏览器适配

- `viewport-fit=cover` + `100dvh`（iOS 地址栏收起/展开不跳动）
- `env(safe-area-inset-bottom)`（刘海屏底部按钮不遮挡）
- 底部按钮用 flex 布局而非 `position:fixed`（键盘顶飞）
- 自定义弹层替代 `alert/confirm`（微信内样式稳定）
- `user-select:none` + `-webkit-tap-highlight-color`（禁用长按菜单和点击高亮）
- 选择用振动反馈而非音效（自动播放被禁）
- 题库请求带 `?t=` 时间戳（避免微信缓存旧题库）
- `localStorage` 存进度（切后台/误返回不丢答案）
- 选项用 `<button>` + `aria-pressed`（可访问性）

## 四、答题流程

```
扫码 → 首页「开始答题」
     → 50 题（单选20/多选20/判断10，随机且题型打乱）
        · 单选：点一项
        · 多选：点多个，可取消
        · 判断：2 个选项
        · 底部进度点 + 顶部进度条
     → 交卷（未答题会提示）
     → 成绩页
        · 大字号总分 + 评价语
        · 统计：答对/答错/未答 + 各题型得分
        · 题号总览网格：绿=对 红=错 灰=未答
           点击任一题号 → 展开该题：题干 / 我的答案 / 正确答案 / 解析
        · 「查看全体详解」→ 按做题顺序，50 题每题下方直接带解析
```

## 五、计分规则

| 题型 | 题量 | 每题 | 小计 |
|---|---|---|---|
| 单选 | 20 | 2 | 40 |
| 多选 | 20 | 2 | 40 |
| 判断 | 10 | 2 | 20 |
| **合计** | **50** | | **100** |

- 多选题：**全对才得分**，漏选/错选/多选均 0 分
- 未作答：0 分

改分值：编辑 `assets/app.js` 的 `CONFIG.score`
改抽题量：编辑 `CONFIG.quota`

## 六、换成你的题库

直接覆盖 `data/questions.sample.json`（或改 `app.js` 里的 `bankUrl` 指向你的文件名），**代码零改动**。

```json
{
  "id": "q_0001",
  "type": "single",
  "question": "题目正文",
  "options": ["选项A", "选项B", "选项C", "选项D"],
  "answer": "A",
  "analysis": "解析正文",
  "knowledge": "知识点标签",
  "difficulty": 1
}
```

| 字段 | 说明 |
|---|---|
| `type` | `single` 单选 / `multi` 多选 / `judge` 判断 |
| `answer` | 单选、判断填单个字母如 `"A"`；**多选填数组**如 `["A","C"]` |
| `options` | 判断题固定 `["正确","错误"]`，答案用 `"A"`/`"B"` |
| `analysis` | 解析，显示在题目下方 |
| `id` | 唯一即可 |

系统启动时会自动校验题量与答案越界，问题会显示在自检页上。

**当前题库是占位用的加减法**（`tools/gen_sample.py` 生成，80 道），你上传真实题库后直接替换即可。

## 七、目录结构

```
quiz/
├─ index.html              答题主页面（扫码进入的就是这个）
├─ cast.html               投放大屏：唯一入口二维码
├─ selfcheck.html          自检页：检查题库 + 显示二维码
├─ server.js               Node 服务：静态托管 + 网卡识别 + 二维码
├─ server.py               Python 服务（同功能，无 Node 时的备选）
├─ start.bat               一键启动
├─ set-quiz-url.bat        手动指定二维码地址
├─ qrcode.png              启动时自动生成
├─ assets/
│  ├─ core.js              核心逻辑（抽题/判分/校验），浏览器与 Node 共用
│  ├─ app.js               界面层（渲染/交互/持久化）
│  ├─ style.css            样式（已适配微信内置浏览器）
│  └─ vendor/qrcode.js     二维码生成（本地，无 CDN 依赖）
├─ data/
│  └─ questions.sample.json  题库（含解析）
├─ tools/
│  ├─ gen_sample.py        生成占位题库
│  ├─ test.js              核心逻辑测试（21 项）
│  ├─ test-ui.js           界面端到端测试（21 项）
│  └─ test-cast.js         大屏页测试（4 项）
├─ deploy.md               公网部署说明
└─ README.md
```
